## UI follow-up decisions

- **Percentiles and tooltips:** The owner's latest feedback restores ordinal suffixes (`st`, `nd`, `rd`, `th`) as small superscripts at 65% of the number's font size. CSV exports retain these suffixes as plain text because CSV does not support superscripts. The tooltip still shows only the other score format plus `n` and `σ`, with a short workload explanation where relevant. Benchmark years remain in CSV metadata, but are removed from UI tooltips.
- **Precision at percentile extremes:** The workload 100s inspected in the preview were rounded: a 4.68 mean maps to 99.6998 and a 4.90 mean to 99.9571. To make the owner's requested extra precision consistent, values in the top/bottom 1% use two decimal places, top/bottom 0.1% use three, and so on, dropping trailing zeros. Cells, opposite-mode tooltips, and CSV exports share the formatter. Fractional ranks use `th`; integer ranks retain `st`/`nd`/`rd`/`th`. Review the 1% cutoff and precision convention. Exact empirical 0/100 values remain possible outside the benchmark averages' range, and scores sharing a hundredth-sized lookup bucket can still tie; formatting cannot distinguish those genuine lookup ties.
- **Default metrics:** Per the owner's follow-up, only Overall Quality and Workload start enabled. Workload is second in the shared statistics configuration, so it precedes Instructor Effectiveness and Intellectual Challenge in the options, displayed columns, exports, and comparison menu when those metrics are enabled.
- **Remembering percentile display:** The owner explicitly replaced the original reset-on-reload behavior for **Show percentiles**. The setting now uses local storage, like search history, under its own key so clearing history does not discard the display preference. The initial choice is still off without a saved preference. If browser storage is unavailable, the current-page toggle still works. No other filters or display choices were made persistent.
- **Professor course labels:** Course separation displays the latest recorded title for each existing course group, with its code(s) in a tooltip. Titles are chosen from this professor's records before applying year/season filters, so filtering does not rename a course. Row identities still use the existing codes, keeping distinct groups separate even if their titles match. CSV exports include the readable Group label and a separate Course codes column. The requested future-tooltip comment is beside the label construction. Review the title choice if a different naming convention is preferred.
- **Professor banner:** The heading is bold, the purple box has square corners, and its course-separation button uses a darker purple.
